# Portfólio

Meu site de portfólio pessoal, desenvolvido para apresentar um pouco sobre mim, meus conhecimentos, tecnologias que estou estudando e meus projetos.

🌐 **Acesse o portfólio:** [Site](https://guilherme-o-lindo.github.io/Portfolio_Site/)

## 📌 Sobre

Este projeto foi desenvolvido como parte de um trabalho dos meus estudos na E.E.E.P de desenvolvimento web voltado para o uso de HTML e CSS.

O site apresenta:

- Uma breve apresentação sobre mim
- Tecnologias e linguagens que estou estudando
- Informações sobre minha formação
- Projetos desenvolvidos
- Formas de contato

## 🛠️ Tecnologias

O projeto foi desenvolvido utilizando principalmente:

- HTML5
- CSS3

Também foram utilizados recursos como:

- Google Fonts
- Git e GitHub
- GitHub Pages
